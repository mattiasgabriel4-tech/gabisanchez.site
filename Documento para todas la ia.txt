    var nav = document.querySelector('header nav');
    if (!btn || !nav) return;
    btn.addEventListener('click', function(){
        var abierto = nav.classList.toggle('abierto');
        btn.classList.toggle('activo', abierto);
        btn.setAttribute('aria-expanded', String(abierto));
    });
    nav.querySelectorAll('a').forEach(function(a){
        a.addEventListener('click', function(){
            nav.classList.remove('abierto');
            btn.classList.remove('activo');
            btn.setAttribute('aria-expanded','false');
        });
    });
})();
</script>

- novedades.html        → página que muestra la lista de noticias
- js/novedades.js       → lee datos desde Google Sheets vía CSV público
- novedades/2026/*.html → páginas individuales de cada noticia

GOOGLE SHEETS (fuente de datos):
URL pública CSV: https://docs.google.com/spreadsheets/d/e/2PACX-1vT339zLE2gGf2BBDHMrFWf1ewHE3P23g7vPGd1m2JXrI2UeMfFjq1Yk95wy7Vey8fXQfFVue1LPkdhZ/pub?output=csv

COLUMNAS DE LA HOJA (fila 1 = títulos, fila 2 en adelante = datos):
A: fecha     → "9 de junio de 2026"
B: titulo    → título de la noticia
C: resumen   → texto corto (2-3 líneas) para la tarjeta
D: etiqueta  → categoría (HCD, Gestión, Transparencia, etc.)
E: archivo   → ruta relativa al HTML: novedades/2026/nombre-archivo.html

PARA AGREGAR UNA NOTICIA NUEVA:
1. Crear el archivo HTML en novedades/[año]/[fecha]-[slug].html
   (usar la plantilla de la sección 7)
2. Subir el HTML a GitHub
3. Abrir la app "Hojas de cálculo de Google" en el celular
4. Agregar una fila nueva ENCIMA de las anteriores (después de fila 1)
5. Completar las 5 columnas
6. Guardar — aparece en el sitio en 1-2 minutos

NOMBRE DE ARCHIVO: formato yyyy-mm-dd-titulo-corto.html
Ejemplo: 2026-06-09-cinco-proyectos-comunicacion.html

FUNCIONALIDADES DE novedades.html:
- Carga automática desde Google Sheets
- Buscador en tiempo real (filtra por título y resumen)
- Botones de filtro por etiqueta (se generan automáticamente)
- Mensaje de "sin resultados" si no hay coincidencias
